Как получить один рабочий QR-код:
1. Опубликуйте содержимое этой папки на GitHub Pages или Cloudflare Pages.
2. Убедитесь, что публичная ссылка открывает index.html.
3. После этого создайте QR-код, ведущий на опубликованную страницу.

Важно:
- Пока страница не опубликована по публичному адресу, окончательный QR-код сделать нельзя.
- Для китайской версии используется имя Maxim Barannikov латиницей, поскольку китайское написание имени не предоставлено.
- Проверьте импорт каждого VCF на iPhone и Android до печати тиража.
